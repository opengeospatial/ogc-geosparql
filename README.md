# OGC GeoSPARQL 1.0

This branch contains the first version of OGC's GeoSPARQL standard, published as GeoSPARQL 1.0: 

* **Specification**
    * online at <http://www.opengis.net/doc/IS/geosparql/1.0>
    * [GeoSPARQL.pdf](spec/11-052r4_OGC_GeoSPARQL.pdf) - local copy PDF file

* **Ontology and all other RDF resources**
    * available in the [GeoSPARQL SWG's part of the Geosemantics DWG's repository for GeoSPARQL 1.0](https://github.com/opengeospatial/geosemantics-semantic-resources/tree/main/resources/geosparql-swg/geosparql-1.0) 

Additionally, this branch contains stand-along GeoSPARQL 1.0 resources created when GeoSPARQL 1.1 was created:

* JSON-LD contexts
* examples
* RIF rules
* translations
* profile declaration
