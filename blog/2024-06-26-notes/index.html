2010 Pull Requests All
  • Extend hasGeometry to allow for GeometryCollections (#525).
  • Union expressions in range expressions are forbidden in OWL2 RL; need for a concrete superclass identified.
  • NC suggested :Geometry :havePart :Geometry with an intermediate Geometry instance.
  • Alternative proposed: make GeometryCollection a subclass of Geometry.
  • NC to work on writing up a subclass proposal.
  • Latitude and Longitude Functions (#526): function defined only for points.
  • TH updated specification to state the function applies only to points.

  • JA suggested easting and northing as applicable to both projected and geodetic systems.
  • [Alignments] Isolating alignments from main specification (#527): waiting for input from OGC.
2045 Other Business All
