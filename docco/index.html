GeoSPARQL ISO

... an ISO-conformant version of GeoSPARQL 1.1

  • This version of GeoSPARQL is a co-adopted version of GeoSPARQL 1.1 to be published by the International Organization for Standardization as ISO 19186-1 which, as of July 2026, is in draft.
  • This standard is being prepared by Technical Committee 211 Geographic information/Geomatics.
