== Functions Summary

[discrete]
[[functions_summary_overview]]
=== B.0. Overview

This annex summarizes all the functions defined in GeoSPARQL, providing descriptions of their parameters and return types.

The value `ogc:geomLiteral` indicates any one of the specific geometry serializations datatypes defined in this Specification, for example <<rdfs_datatype_geo_wktliteral, `geo:wktLiteral`>>.

The geometry subtypes - Polygon, Point, CellList etc. - are the _Simple Features specification_ <<OGCSFACA>> <<ISO19125-1>> or DGGS types, as implemented by the various geometry serialization specifications referenced here. See <<properties_geometry_serializations>> for the individual specification references.
