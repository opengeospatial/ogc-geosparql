# GeoSPARQL Next

This folder of the [GeoSPARQL version control repository](https://github.com/opengeospatial/ogc-geosparql/) contains source files for the in-development, 'Next', variant of GeoSPARQL.

This variant is expected to be published as an OCG Standard in late 2026/early 2027, and it will replace [GeoSPARQL 1.1](http://www.opengis.net/doc/IS/geosparql/1.1) as the current version.

See [the GeoSPARQL Next section of the documentation](https://opengeospatial.github.io/ogc-geosparql/) for readable versions of this source data.
